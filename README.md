## Problem Statement

### The Challenge

Pregnancy care in many regions, especially in developing countries, faces critical challenges that prevent expectant mothers from receiving timely, reliable, and accessible healthcare guidance:

#### 1. **Limited Access to Healthcare Professionals**
- **Geographic Barriers**: Many expectant mothers live in remote areas with limited access to specialized pregnancy care
- **High Costs**: Regular doctor consultations are expensive, making quality healthcare unaffordable for many families
- **Time Constraints**: Healthcare professionals have limited availability, making it difficult to get immediate answers to urgent questions
- **Language Barriers**: Non-English speakers struggle to find reliable pregnancy information in their native language

#### 2. **Information Overload and Reliability Issues**
- **Conflicting Information**: The internet is flooded with contradictory pregnancy advice, making it difficult to find trustworthy guidance
- **Lack of Personalization**: Generic information doesn't account for individual pregnancy stages, health conditions, or medical history
- **No 24/7 Support**: Expectant mothers often have questions outside regular clinic hours, especially during emergencies or concerns
- **Language Limitations**: Most reliable pregnancy resources are in English, excluding millions of non-English speakers

#### 3. **Inefficient Health Tracking and Management**
- **Manual Record Keeping**: Traditional methods of tracking pregnancy progress, prescriptions, and health records are disorganized
- **No Continuous Monitoring**: There's no system to track daily health patterns, symptoms, or medication adherence
- **Prescription Management**: Physical prescription papers are easily lost, damaged, or difficult to organize
- **Lack of Follow-up**: Limited mechanisms for healthcare providers to monitor patient progress between visits

#### 4. **Communication Gaps**
- **Delayed Responses**: Questions submitted to healthcare providers often take days to receive responses
- **Limited Interaction**: Minimal opportunities for mothers to ask follow-up questions or clarify concerns
- **No Emergency Support**: No immediate access to guidance during urgent situations or health concerns
- **Inadequate Documentation**: Poor tracking of health history, making it difficult to provide context during consultations

### Impact of These Problems

- **Delayed Care**: Critical health issues may go unnoticed or untreated
- **Increased Anxiety**: Lack of reliable information causes unnecessary stress and worry
- **Poor Health Outcomes**: Inadequate monitoring and guidance can lead to preventable complications
- **Healthcare Inequality**: Geographic and economic barriers create disparities in care quality
- **Language Exclusion**: Non-English speakers are systematically excluded from quality healthcare information

## Core Working Flows

### 1. User Registration Flow

#### For Expectant Mothers:
1. User visits the MomsCare homepage
2. Clicks "Get Started as a Mother" or "Create Account"
3. Fills registration form with name, email, and password
4. System creates account and automatically logs user in
5. User is redirected to dashboard where they can complete their profile
6. Profile completion includes pregnancy stage, medical history, and emergency contacts

#### For Healthcare Professionals:
1. User visits homepage and clicks "Join as Health Worker"
2. Selects role (Doctor, Nurse, or Other health worker)
3. Fills comprehensive application form including:
   - Personal information (name, email, phone)
   - Professional credentials (specialty, BMDC number for doctors)
   - Hospital/clinic information
   - Profile picture upload
4. System saves application with "pending" status
5. Admin reviews application and approves or rejects
6. Upon approval, healthcare professional receives notification and can login
7. System routes to appropriate dashboard based on role (doctor or nurse)

#### For Administrators:
1. Super admin logs in with credentials
2. System verifies super admin status
3. Admin gains access to full administrative dashboard
4. Admin can create additional editor accounts for platform management

### 2. User Login Flow

#### Authentication Process:
1. User enters email and password on login page
2. System validates credentials against stored user data
3. For healthcare professionals, system checks approval status
4. If approved, system generates secure authentication token
5. Token is stored in browser and used for all subsequent requests
6. User is redirected to appropriate dashboard based on role
7. System maintains session until user logs out or token expires

#### Security Checks:
- Password verification using secure hashing
- Account status verification (active, paused, or deleted)
- Role-based access control
- Token expiration and refresh mechanism

### 3. AI Chat Interaction Flow

#### For Logged-In Users:
1. User navigates to chat interface
2. System loads user's profile data and health history
3. User types question or uploads image
4. System processes query through multiple stages:
   - Language detection
   - Question classification (personal vs. general)
   - Context gathering (profile, prescriptions, daily journals)
   - Knowledge base search
   - AI response generation
5. AI generates personalized response using gathered context
6. Response is displayed to user
7. Conversation history is saved for future reference

#### For Guest Users:
1. User accesses chat without logging in
2. System provides basic AI support without personalization
3. No profile data or history is used
4. Responses are general pregnancy guidance
5. User can register to unlock personalized features

### 4. Question Submission to Healthcare Professionals

1. Mother navigates to "Ask a Question" section
2. Types question and submits
3. System creates question record with "pending" status
4. Question appears in healthcare professional dashboard
5. Doctor/nurse reviews question and provides answer
6. System notifies mother of response
7. Mother can view answer and ask follow-up questions
8. Conversation thread is maintained for context

### 5. Prescription Management Flow

1. Mother uploads prescription image from dashboard
2. System uploads image to secure cloud storage
3. Image is processed and stored with metadata
4. Prescription appears in mother's prescription list
5. When mother asks AI about medications, system can analyze prescription images
6. AI provides guidance based on prescription content
7. Prescriptions are accessible anytime for reference

### 6. Daily Health Tracking Flow

1. Mother accesses daily journal from dashboard
2. System prompts for daily health information:
   - Symptoms experienced
   - Mood and emotional state
   - Sleep quality and duration
   - Diet and nutrition
   - Medication adherence
3. Mother enters information and saves
4. System stores journal entry with timestamp
5. Data is used to personalize AI responses
6. System can identify patterns and provide recommendations
7. Healthcare professionals can review journal entries when answering questions

  - Cannot create other editors
  - Cannot delete super admin

### Authentication Mechanism

#### Token-Based Authentication:
1. **Login Process**: User provides email and password
2. **Credential Verification**: System verifies against stored, securely hashed passwords
3. **Token Generation**: Upon successful verification, system generates JWT (JSON Web Token)
4. **Token Storage**: Token stored in browser's local storage
5. **Request Authentication**: All subsequent requests include token in header
6. **Token Validation**: Each request validates token before processing
7. **Session Management**: Token expires after 7 days, requiring re-authentication

#### Security Features:
- **Password Hashing**: All passwords stored using bcrypt with salt
- **Account Status Checking**: System verifies account is active before allowing access
- **Role Verification**: Each request checks user role and permissions
- **Token Expiration**: Automatic logout after token expiration
- **Secure Storage**: Tokens stored securely, never in cookies or URL

### User Connection Flow

#### Initial Connection:
1. User visits MomsCare website
2. System checks for existing authentication token
3. If token exists and valid, user is automatically logged in
4. If no token, user sees login/registration options
5. User chooses to login or register

#### Session Management:
1. User performs actions requiring authentication
2. System sends token with each request
3. Backend validates token and user status
4. If valid, request is processed
5. If invalid or expired, user is redirected to login
6. User can manually logout, which clears token

#### Multi-Device Support:
- Tokens work across devices
- User can login from multiple devices simultaneously
- Each device maintains independent session
- Logout from one device doesn't affect others

## AI Chat System Workflow

### Complete AI Response Generation Process

The AI chat system operates through a sophisticated multi-stage process to deliver accurate, personalized responses:

#### Stage 1: Input Processing
1. **Message Reception**: System receives user message (text and/or image)
2. **Language Detection**: Automatically detects if message is in English, Bangla, or Banglish
3. **Question Classification**: Determines if question is personal (about user) or general (about pregnancy in general)
4. **Image Processing**: If image attached, system prepares it for AI analysis

#### Stage 2: Context Gathering
1. **Profile Data Retrieval**: If user is logged in, system retrieves:
   - Pregnancy stage (weeks/days pregnant)
   - Medical history (conditions, medications, allergies)
   - Blood group and health information
   - Emergency contacts
2. **Prescription Analysis**: If user has uploaded prescriptions, system retrieves relevant ones
3. **Daily Journal Data**: Retrieves recent journal entries for context
4. **Previous Doctor Q&A**: Retrieves past questions and doctor responses
5. **Context Filtering**: AI intelligently decides which context sources are relevant to current question

#### Stage 3: Knowledge Base Search (RAG System)
1. **Query Preparation**: System prepares search query based on user's question
2. **Language-Specific Search**: 
   - English questions search English knowledge base
   - Bangla questions search Bangla knowledge base
   - Banglish questions are translated to English for better search results
3. **Relevance Scoring**: System scores each knowledge base entry for relevance:
   - Question match: 10 points
   - Answer match: 5 points
   - Tag match: 8 points
   - Context match: 6 points
   - Exact phrase match: 50+ points bonus
4. **Top Results Selection**: System selects top 3 most relevant Q&A pairs
5. **Context Formatting**: Selected knowledge is formatted for AI prompt

#### Stage 4: Medical Guidelines Retrieval
1. **Trimester Detection**: System identifies user's pregnancy trimester
2. **Guideline Search**: Searches medical guidelines database based on:
   - Question topic
   - Pregnancy stage
   - Health conditions
3. **Relevant Guidelines**: Retrieves top 5 most relevant medical guidelines
4. **Guideline Formatting**: Formats guidelines for AI context

#### Stage 5: AI Response Generation
1. **Prompt Construction**: System builds comprehensive prompt including:
   - User's question
   - Relevant profile context
   - Knowledge base Q&A pairs
   - Medical guidelines
   - Prescription information (if applicable)
   - Daily journal data (if relevant)
   - Language instruction (respond in user's language)
2. **Model Selection**: 
   - If image attached: Uses vision-capable AI model
   - If text only: Uses advanced text model
3. **AI Processing**: AI model processes prompt and generates response
4. **Response Validation**: System checks response quality and completeness
5. **Response Cleaning**: Removes AI artifacts and formatting issues
6. **Language Verification**: Ensures response matches user's language

#### Stage 6: Response Delivery
1. **Response Display**: Formatted response shown to user
2. **Conversation Saving**: Response saved to conversation history
3. **Context Update**: System updates context for future questions in same conversation

### Intelligent Context Selection

The system uses AI to intelligently decide which context sources to include:

1. **Question Analysis**: AI analyzes question to determine what information is needed
2. **Context Decision**: AI decides:
   - Whether to use profile data (for personal questions)
   - Whether to use prescription data (for medication questions)
   - Whether to use daily journal (for symptom tracking questions)
   - Whether to use doctor Q&A (for follow-up questions)
3. **Efficiency Optimization**: Only relevant context is included, reducing processing time and improving accuracy

### Multi-Language Processing

#### Language Detection:
- System automatically detects language from user input
- Supports English, Bangla (Bengali script), and Banglish (Romanized Bangla)
- Detection happens before any processing

#### Banglish Handling:
- Banglish queries are translated to English for knowledge base search
- This ensures better search results (knowledge base is primarily in English)
- AI response is generated in Bangla (Bengali script) to match user preference
- User receives response in their preferred language

#### Response Language Matching:
- System ensures AI responds in same language as user's question
- English questions → English responses
- Bangla questions → Bangla responses
- Banglish questions → Bangla responses (in Bengali script)

### Vector Search and Embeddings

MomsCare uses vector search to find the most relevant information for user queries. This system converts text into numerical vectors (embeddings) and compares them to find semantically similar content.

#### Embedding System Architecture:
1. **Client-Side Embeddings**: Uses WebAssembly in the browser for fastest performance
2. **Server-Side Fallback**: When client-side fails, uses Hugging Face API
3. **Keyword Search**: Final fallback when embeddings aren't available

#### Setting Up Free Embedding Service:

To enable vector search, you need to configure a free embedding service:

1. **Hugging Face (Recommended)**:
   - Sign up at [huggingface.co](https://huggingface.co)
   - Get your API token from Settings → Access Tokens
   - Add `HF_TOKEN=your_token_here` to your environment variables

2. **Alternative Services**:
   - Cohere Embed API
   - OpenAI Ada Embeddings
   - Custom embedding services

For detailed setup instructions, see [docs/embedding-setup.md](docs/embedding-setup.md)

## Data Retrieval & Knowledge Base System

### Knowledge Base Architecture

MomsCare maintains a comprehensive dual-language knowledge base system:

#### Dataset Structure:
- **English Dataset**: 677 Q&A pairs covering pregnancy topics
- **Bangla Dataset**: 677 Q&A pairs (matched translations)
- **Medical Guidelines**: Comprehensive pregnancy care guidelines
- **Question Tags**: Each Q&A tagged with relevant topics
- **Context Information**: Additional context for each Q&A pair

### Data Retrieval Process (RAG - Retrieval-Augmented Generation)

#### Step 1: Query Analysis
1. System receives user question
2. Extracts keywords and important terms
3. Identifies question intent (what user is asking about)
4. Determines search language based on user's input language

#### Step 2: Dataset Search
1. **Language Selection**: 
   - English questions → Search English dataset
   - Bangla questions → Search Bangla dataset
   - Banglish questions → Translate to English, then search English dataset

2. **Scoring Algorithm**: For each Q&A pair in dataset:
   - **Question Match**: If user's question keywords match Q&A question → 10 points
   - **Answer Match**: If keywords match Q&A answer → 5 points
   - **Tag Match**: If keywords match Q&A tags → 8 points
   - **Context Match**: If keywords match Q&A context → 6 points
   - **Exact Phrase**: If exact phrase matches → 50+ points bonus

3. **Relevance Filtering**: Only Q&A pairs with score ≥ 25 points are considered
4. **Ranking**: Results sorted by score (highest first)
5. **Top Selection**: Top 3 most relevant Q&A pairs selected

#### Step 3: Context Formatting
1. Selected Q&A pairs are formatted for AI prompt
2. Format includes:
   - Question from knowledge base
   - Answer from knowledge base
   - Relevant tags and context
3. Formatted in user's language (English or Bangla)

#### Step 4: Integration with AI
1. Formatted knowledge base context added to AI prompt
2. AI uses this context along with user's question to generate response
3. AI is instructed to use knowledge base only if directly relevant
4. If knowledge base doesn't match, AI uses its own knowledge

### Medical Guidelines Retrieval

#### Guidelines Database:
- Comprehensive pregnancy care guidelines
- Organized by trimester and topic
- Includes safety information, recommendations, and warnings

#### Retrieval Process:
1. System identifies user's pregnancy trimester
2. Searches guidelines based on:
   - Question topic
   - Pregnancy stage
   - Health conditions mentioned
3. Retrieves top 5 most relevant guidelines
4. Formats guidelines for AI context
5. AI incorporates guidelines into response

### Data Loading and Caching

#### Initial Load:
- Knowledge base datasets loaded when server starts
- Data stored in memory for fast access
- Both English and Bangla datasets loaded simultaneously

#### Caching Strategy:
- Frequently accessed data cached in memory
- User profile data cached for quick access
- Cache refreshed periodically to ensure accuracy

#### Performance Optimization:
- Search operations optimized for speed
- Parallel processing for multiple data sources
- Efficient scoring algorithm minimizes processing time
