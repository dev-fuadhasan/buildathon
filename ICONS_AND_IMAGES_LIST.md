Consider using:
- **Heroicons** (https://heroicons.com/)
- **Lucide Icons** (https://lucide.dev/)
- **Font Awesome** (https://fontawesome.com/)
- **Material Icons** (https://fonts.google.com/icons)

Or create custom SVG icons matching your brand style.

---

## NOTES

1. All icons should be in SVG format for scalability (except app icons which need PNG)
2. Icons should support both light and dark themes (or use CSS filters)
3. Icons should be optimized for web (minified SVG)
4. Consider creating an icon component system for easy replacement
5. All icons should be accessible (proper alt text/aria labels)
